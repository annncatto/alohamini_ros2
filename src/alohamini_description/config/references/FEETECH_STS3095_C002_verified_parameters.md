# STS3095-C002 原厂参数与负载速度模型

> 来源等级：用户确认的原厂参数，2026-08-10 写入资产。

| 参数 | 数值 |
| --- | --- |
| 工作电压 | 12 V |
| 空载速度 | 0.322 s/60°（31 RPM） |
| 空载角速度 | 3.25 rad/s |
| 堵转扭矩 | 95 kg·cm = 9.32 N·m |
| 额定扭矩 | 22.5 kg·cm = 2.21 N·m |
| 堵转电流 | 9.8 A |
| 额定电流 | 2.2 A |
| Kt | 10 kg·cm/A |
| 减速比 | 1:399 |
| 回差 | ≤0.5° |

负载速度近似模型：

$$
\omega(\tau)=\omega_0\left(1-\frac{\tau}{\tau_{stall}}\right)
$$

$$
\omega(\tau)=3.25\left(1-\frac{\tau}{9.32}\right)
$$

在额定扭矩 `2.21 N·m` 下，近似 `2.4793455 rad/s`。
